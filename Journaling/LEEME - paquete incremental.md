# Paquete incremental: Git y GitHub

Este ZIP contiene únicamente las notas del área **Journaling y control de versiones**.

## Cómo incorporarlo

1. Abre la carpeta raíz del vault de knowledge en Ubuntu.
2. Extrae el ZIP dentro de esa carpeta, conservando las rutas.
3. Si Obsidian o el gestor de archivos pregunta si debe reemplazar una nota existente, no la reemplaces sin comparar primero el contenido.
4. Comprueba que las notas aparecen en `06 Journaling y control de versiones`.

Si ya habías incorporado estas mismas notas desde el paquete completo actualizado, no necesitas volver a copiarlas.

## Contenido

- GitHub como repositorio de seguimiento del TFG
- Configuración local de Git para el journaling
- Autenticación SSH con GitHub
- Estructura del repositorio de journaling
- Automatización con Obsidian Git (tarea pendiente)
- MOC de journaling y control de versiones

Este paquete documenta la configuración existente del **journaling vault**. No inicializa Git ni cambia la configuración del **knowledge vault**; eso se hará por separado después de integrar las notas.
